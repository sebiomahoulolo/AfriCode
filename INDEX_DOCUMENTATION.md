## 🗺️ Parcas d'Usage

### Je veux comprendre le projet rapidement
1. Lire **[PRESENTATION_RESUME.md](PRESENTATION_RESUME.md)** (10-15 min)
2. Consulter les fonctionnalités principales
3. Regarder le modèle économique

### Je veux développer sur le projet
1. Lire **[README.md](README.md)** pour l'installation (20 min)
2. Lire **[DOCUMENTATION_TECHNIQUE.md](DOCUMENTATION_TECHNIQUE.md)** pour l'architecture (60-90 min)
3. Consulter **[ARCHITECTURE.md](ARCHITECTURE.md)** pour la structure (15 min)
4. Explorer le code source

### Je veux créer un cours
1. Lire **[GUIDE_DEMARRAGE_RAPIDE.md](GUIDE_DEMARRAGE_RAPIDE.md)** section formateurs (15 min)
2. Consulter **[GUIDE_AJOUT_COURS_COMPLET.md](GUIDE_AJOUT_COURS_COMPLET.md)** (25 min)
3. Commencer à créer !

### Je veux suivre un cours
1. Lire **[GUIDE_DEMARRAGE_RAPIDE.md](GUIDE_DEMARRAGE_RAPIDE.md)** section apprenants (15 min)
2. Explorer le catalogue
3. S'inscrire à un cours

### Je veux déployer le projet
1. Lire **[README.md](README.md)** pour l'installation (20 min)
2. Lire **[DEPLOYMENT_GUIDE.md](DEPLOYMENT_GUIDE.md)** (30 min)
3. Configurer le serveur
4. Déployer

### Je veux présenter le projet
1. Lire **[PRESENTATION_RESUME.md](PRESENTATION_RESUME.md)** (10-15 min)
2. Préparer une présentation basée sur ce document
3. Utiliser les chiffres et statistiques

### Je veux contribuer au projet
1. Lire **[README.md](README.md)** section contribution (5 min)
2. Lire **[DOCUMENTATION_TECHNIQUE.md](DOCUMENTATION_TECHNIQUE.md)** (60-90 min)
3. Fork le projet
4. Créer une branche
5. Soumettre une PR
