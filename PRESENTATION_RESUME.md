# 🚀 AfriCode - Présentation Résumée

## 🎯 Vision en Une Phrase
**AfriCode** est la plateforme d'apprentissage en ligne qui démocratise l'éducation numérique en Afrique en permettant à chacun d'apprendre, d'enseigner et de grandir.

## 🛠️ Stack Technique

### Backend
- **PHP 8.2+** : Langage moderne et performant
- **Laravel 12** : Framework PHP robuste et sécurisé
- **Livewire 3** : Composants interactifs sans JavaScript complexe
- **MySQL/PostgreSQL** : Base de données relationnelle

### Frontend
- **Blade Templates** : Moteur de templates Laravel
- **TailwindCSS** : Framework CSS utility-first
- **Bootstrap 5** : Composants UI
- **JavaScript ES6+** : Interactivité moderne
- **AOS** : Animations au scroll

### Services
- **Stripe** : Paiements sécurisés
- **PayPal** : Alternative de paiement
- **DomPDF** : Génération de certificats
- **PHPMailer** : Emails transactionnels
- **Laravel Socialite** : Auth sociale
