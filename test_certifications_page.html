Note d'Architecture

Cette page s'intègre parfaitement dans l'écosystème AfriCode existant, utilisant la même structure de base de données (table certifications) et respectant la charte graphique établie. La méthode calculateAverageCompletionTime() offre des statistiques enrichies pour l'utilisateur.
