1. Inclure les classes CSS responsive existantes
2. Utiliser les breakpoints standardisés 
3. Tester sur tous les points de rupture
4. Vérifier l'accessibilité mobile

### Pour modifier les breakpoints :
1. Modifier `formateur-responsive.css`
2. Ajuster `formateur-responsive.js` si nécessaire
3. Mettre à jour la documentation
